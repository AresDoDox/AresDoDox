### Xin chào, tôi là Đỗ Thành Cao Thái (AresDoDox) 👋

Tôi là Kỹ sư Front-End với hơn 6 năm kinh nghiệm xây dựng ứng dụng web, hiện đang định hướng phát triển chuyên sâu lên Full-Stack.

---

### 🛠️ Kỹ năng & Công nghệ

* **Làm việc hàng ngày:** React.js, TypeScript, JavaScript (ES6+), HTML5, CSS3 / SASS / Tailwind CSS.
* **Hệ thống cũ & Bảo trì:** jQuery, Bootstrap, tối ưu tương thích đa trình duyệt (Cross-browser).
* **Mở rộng Full-Stack:** Next.js, Node.js (ExpressJS / NestJS), Prisma ORM, PostgreSQL / TiDB Cloud.
* **Công cụ & Luồng làm việc:** Git, RESTful APIs.
